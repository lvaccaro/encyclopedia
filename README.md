# The Liquid Encyclopedia

Liquid digital assets like stablecoins, tokenized securities, and bonds.

Integrate a liquid web wallet that runs in the browser, based on [LWK wasm](https://github.com/Blockstream/lwk/tree/master/lwk_wasm).

See live site at [encyclopedia.money](https://encyclopedia.money)

## Liquid web wallet

Watch-only mode works in any modern browser, connection with JADE requires web serial and works on chrome, chromium, edge.

## Supported listing services
- [Blockstream](https://blockstream.info/liquid/assets) Liquid asset registry
- [Bitfinex Securities](https://www.bitfinex.com/securities) Access to tokenised equities, bonds and investment funds.
- [Sideswap](https://sideswap.io) Decentralized trading
- [Stokr](https://stokr.io) Alternative investment marketplace
